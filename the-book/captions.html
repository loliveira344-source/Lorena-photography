Add captions

Every photo currently on the-book is listed below, grouped by chapter, with a box under each one for its description. Type your captions, then use each chapter's "Copy code" button and paste the result into the-book/index.html.

How to use this:
  1. Write a caption in any box below (you don't have to do them all at once).
  2. Click Copy code at the top of that chapter's section.
  3. Open the-book/index.html in a text editor, search for that chapter's name (e.g. search slug: "primeira-parte-origens"), and replace everything from photos: [ down to the matching ] with what you just copied.
  4. Save, then re-upload the-book to GitHub the same way as always.
